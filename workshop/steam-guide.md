TITLE: R.A.T.S. Flotilla: a test bench for Sea Power
DESCRIPTION: Is it the game, or is it your mods? Keep several Sea Power installs side by side, each with its own mods, settings and saves, and leave your Steam install alone.
CATEGORY: Modding

=== SECTION: What it is for ===
[i]R.A.T.S. – Reconnaissance, Acoustics, Terrain & Signals[/i]

Something broke. Was it the game, or one of the mods you swore were fine? [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3836624723]R.A.T.S. Flotilla[/url] is a small Windows app that keeps several Sea Power installs side by side, each with its own mods, settings and saves.

[list]
[*][b]Bug reports:[/b] reproduce the problem on a clean install with no mods and no loader
[*][b]Testing mod sets:[/b] load one copy to the gills while your everyday game stays as it is
[*][b]Game updates:[/b] keep the older version next to the new one and compare
[*][b]Modders:[/b] try a build on its own copy
[/list]

It is an app, not a game mod. Each copy takes about 19 GB of disk.

=== SECTION: Getting it ===
[olist]
[*]Subscribe to [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3836624723]R.A.T.S. Flotilla on the Workshop[/url]. Its entry in the game's Mods menu does nothing, so leave it off
[*]Open [i]steamapps\workshop\content\1286220[/i] in the Steam library that holds Sea Power, then the folder [i]3836624723[/i]
[*]Start [b]SeaPowerFlotilla.exe[/b] once. It moves to a safe place on your PC and offers a desktop shortcut. From then on, start it from there
[/olist]

Prefer a plain download? Get the zip from [url=https://github.com/struckl/SeaPowerFlotilla/releases/latest]GitHub[/url], unzip it to a folder that stays, and start the exe.

Windows may say "unknown publisher": More info, then Run anyway. No admin rights needed. It needs .NET Framework 4.8, which every Windows 10 and 11 has.

=== SECTION: Making a copy ===
Press [b]New copy...[/b], give it a name that says what it is for, and pick one of two kinds:

[list]
[*][b]Clean:[/b] only the game's own files. No mod loader, no local mods, no missions, fresh settings with no mods enabled. The one for bug reports
[*][b]Copy of my setup:[/b] everything from your Steam install, including the mod loader, local mods, missions, settings, enabled mods with their order, and saves. The starting point for a big mod set
[/list]

Copies go to a folder called [i]Sea Power Flotilla[/i] next to your Steam library. [b]Change...[/b] picks another one. [b]Rename...[/b] changes a copy's name later.

=== SECTION: Playing and managing mods ===
Steam has to be running. Select an install and press [b]Play[/b]. [b]Desktop shortcut[/b] starts a copy directly.

[b]Mods...[/b] works on one copy at a time. Start a new copy once first, because the game has to write its settings:
[list]
[*]Switch mods on or off and set their order
[*]Add a mod from a folder or a .zip to that copy alone
[*]See which game version each mod was made for
[/list]

Mods with scripts need a mod loader in that copy: Keel or Anchor Chain, either one. A Clean copy has none, on purpose.

=== SECTION: After a game update ===
Steam updates only its own install. The list marks copies that are behind. Press [b]Update[/b] to refresh a copy's game files and keep its mods, missions, settings and saves.

Want to keep an older version? Don't press Update on that copy.

=== SECTION: Good to know ===
[list]
[*]Workshop subscriptions belong to your Steam account, so every copy sees them. Which ones are switched on, and in what order, is kept per copy
[*]One Sea Power at a time. While a copy runs, don't start the game from your Steam library
[*]Your Steam install is never changed. While a copy runs, the game's data folder is switched to the copy's and put back when the game closes
[*]If the PC goes off while a copy runs, your Steam settings come back the next time you open Flotilla
[*]Copies are not synced to Steam Cloud
[/list]
