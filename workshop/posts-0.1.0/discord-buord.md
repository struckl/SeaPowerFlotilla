**R.A.T.S. Flotilla – a test bench for Sea Power**
Stop testing on the install you actually play.

Several Sea Power installs side by side, each with its own mods, settings and saves:
• **Clean install in one click:** no mods, no loader. Is it the game or your mod? Now you know
• **One copy per test:** try a build or a giant mod list while your everyday game stays as it is
• **Old and new game version** next to each other
• **Mods per copy:** on/off, load order, or add a folder or zip to just that copy
• **Name your copies**, so "Pacific, 80 mods, pray" stays away from "Bug reports"
• Your Steam install is left alone
