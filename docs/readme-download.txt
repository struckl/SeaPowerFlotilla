R.A.T.S. Flotilla
Reconnaissance, Acoustics, Terrain & Signals

Several Sea Power installs on one PC, each with its own mods, settings and saves.
For example: a clean one for bug reports, one with a big Anchor Chain mod set, one for trying things out.

START
  Put SeaPowerFlotilla.exe in a folder that stays (desktop shortcuts point to it) and start it.
  Windows may warn that the app is from an unknown publisher: "More info" -> "Run anyway".
  Nothing to install; it needs .NET Framework 4.8, which every Windows 10 and 11 has.

USE
  New copy...       Clean (only the game's files, no mods, fresh settings) or a copy of your current setup.
                    About 19 GB each, in "Sea Power Flotilla" next to your Steam library (Change... to move it).
  Play              Starts the selected install. Steam must be running. One Sea Power at a time.
  Mods...           For one copy: mods on/off, their order, add a mod folder or .zip to this copy only.
  Update            After Steam updated the game: brings a copy's game files up to date, keeps its mods and saves.
  Desktop shortcut  "Sea Power (name)" on the desktop, starts that copy directly.
  Delete...         Removes a copy for good. The Steam install is never touched.

GOOD TO KNOW
  - Workshop subscriptions belong to your Steam account, so every copy sees them. Which ones are enabled,
    and in what order, is kept per copy.
  - While a copy runs, the game's data folder (AppData\LocalLow\Triassic Games\Sea Power) is swapped for the
    copy's UserData folder; when the game closes it is put back. Do not start Sea Power from the Steam library
    while a copy runs.
  - Steam updates only its own install. Press Update for each copy after a game update - or don't, if you want
    to keep an older game version around.
  - Copies are not synced to Steam Cloud.
